Installing

  • Every Install button now checks the file before installing. Before, only Install straight after a download (with Inspect APK after download on) or on the Details screen checked the signature and compatibility. The Install button in Downloads, and on a download you came back to later, checked only the checksum. Now:

    • it warns you and asks you to confirm if the app is signed by someone else or may not work fully on your device;
    • it refuses a file Android can't install on this device, and says why.

    The check can take a few seconds for a large app; the button shows Checking… meanwhile.

  • Open installer automatically now waits for the inspection. With Inspect APK after download off, it no longer opens the installer on the checksum alone; tap Install instead.

Good to know
  • The privacy description now mentions that Download and install SAI always contacts F-Droid, even when F-Droid is switched off for searching.
  • The warning on search results now says the repository flags the app for non-free dependencies or tracking, because it appears for both. Before, an app flagged only for tracking was described as depending on a non-free service.
  • Settings text is more precise about where downloads are stored and about touch targets, which are larger on every screen, not only wide ones.
