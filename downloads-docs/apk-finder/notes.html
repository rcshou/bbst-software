New
  • Check for updates, in Settings > About. It asks the download site whether a newer version of APK Finder is published and, if there is one, offers to open the download page. It only ever checks when you tap it, and it never downloads or installs anything by itself.
Easier to use in a car
  • Tapping anywhere on a search result now opens that app, not only the small repository line. If an app is in more than one repository, tapping a repository line still opens that one.
Settings
  • All three repositories are now on when you install the app: F-Droid, IzzyOnDroid and APKPure. Before, only F-Droid was. If you already have APK Finder, your own settings are kept as they are.
  • While APKPure is on, your search terms are sent to apkpure.com. Turn it off in Settings > Repositories if you would rather they were not.
