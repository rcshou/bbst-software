Checking a download

Compare the checksum of the file you downloaded with the one listed above. They must match exactly; if they do not, delete the file and download it again.

  • Windows — in PowerShell, Get-FileHash .\file-name
  • macOS and Linux — in Terminal, shasum -a 256 file-name
