Photo Statistics

What your selection actually holds

Private release Version 2.0.0 · Plugin · macOS

Tells you what a selection actually holds — how many RAW files, how many HEIC, how many in formats the rest of your workflow cannot read — and can check the HEIC files among them for ones that no longer open as HEIC at all.

Categories

All tools 16 Business 5 Web & Mobile 2 Lightroom 6 Geoscience 3

Published builds are listed under Downloads. Everything else is distributed on request.

What it reports

Run Library > Plug-in Extras > File type statistics on selection. A dialog counts the selection by kind — total, RAW, HEIC, the formats the similar-photo comparison can read, and everything else — and lists the extensions it found. The counts come from file extensions, so they describe what the files say they are.

The HEIC check

Tick Check for corrupted HEIC files and every selected .heic or .heif file is opened with libheif and asked for its primary image. Files that fail are added to a collection named CorruptedHIEC. Later runs add to that collection rather than replacing it, and the plugin writes nothing else to the catalog or to the files.

Instead of

Promising to find every damaged file. The check catches files that are no longer valid HEIC containers. A file whose header survived but whose image data was cut short still passes — that was tested against a real truncated file — so a clean result means the container is intact, not that every pixel is.

Status, stated plainly

The HEIC check uses a native helper built for Apple Silicon Macs, and the plugin is Mac-only. It has been tested in Lightroom Classic on a Mac.

Licensing

The plugin’s own code is licensed under Apache 2.0. Its HEIC helper bundles libheif and libde265, which are LGPL, and the x265 encoder, which is GPL 2.0.
